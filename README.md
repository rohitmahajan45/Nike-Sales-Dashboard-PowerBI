## 📌 About The Project

The **Nike Sales Analytics Dashboard** is an interactive Power BI business intelligence project designed to analyze sales and profitability across different **regions, states, cities, retailers, products, and sales methods**.

The dashboard transforms raw Excel data into meaningful business insights through **KPIs, interactive filters, DAX calculations, charts, maps, and data modeling**.

### 🎯 Main Objective

> **Turn raw sales data into actionable insights that help businesses understand performance, identify trends, and support data-driven decisions.**

# 🔍 Business Questions Answered

This dashboard helps answer questions such as:

* Which region generates the highest profit?
* Which cities are performing the best?
* Which retailers contribute the most sales?
* Which sales method generates the highest volume?
* How does performance change over time?
* Which states contribute most to overall sales?
* What are the major sales and profit trends?
